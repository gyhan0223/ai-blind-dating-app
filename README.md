# 본심 — 사진 없는 AI 블라인드 소개팅 (MVP)

> **"서로의 얼굴은 AI만 먼저 봅니다."**
> 사진을 직접 보지 않고도, AI가 서로의 외모 취향·성격·가치관·대화 궁합을 학습해
> 실제로 잘 맞을 가능성이 높은 사람을 소개하는 데이팅 앱의 Phase 1 (Matching MVP) 구현입니다.

## 실행 방법

```bash
npm install
npm run dev
# http://localhost:3000
```

첫 실행 시 SQLite DB(`data/app.db`)가 자동 생성되고, 매칭이 바로 동작하도록
데모 사용자 40명이 시드됩니다.

**데모 로그인**: 아무 휴대전화 번호(예: 010-1234-5678) 입력 → 인증번호 `000000`

## 구현된 기능 (계획서 28장 MVP 범위)

### 가입 / 인증
- 휴대전화 본인 인증 (MVP는 모의 구현 — 실서비스에서는 PASS/NICE 연동으로 교체)
- 성인 확인 (만 19세 미만 가입 불가)
- 얼굴 라이브니스 인증 + 다각도 촬영 (모의 구현 — 얼굴 특징 벡터 생성)
- 상대에게는 **"본인 인증 완료 ✓ / 얼굴 인증 완료 ✓"** 배지만 표시

### 프로필 / 취향
- 기본 정보 (나이·지역·키·직업·학력·흡연·음주·종교·MBTI)
- 라이프스타일 8개 축, 행동 기반 성격 5개 축
- 연애 가치관 (결혼·자녀·장거리) + 과거 관계 가치관 (**민감 항목은 답변 거부 가능**)
- 연애 스타일 5개 축
- **Preference와 Dealbreaker 분리** — Dealbreaker는 점수가 아니라 필터
- **개인별 매칭 중요도 가중치** (외모/성격/가치관/생활/연애관/대화, 사용자마다 다름)
- **외모 Preference Test** — AI 생성 가상 얼굴(특징 벡터 기반 일러스트) A/B 선택으로
  외모 취향 벡터 학습

### 매칭 (`lib/matching.ts`)
- **양방향 AI 매칭**: A→B, B→A 예상 호감도를 각자의 가중치로 계산,
  조화 평균으로 종합 (한쪽만 높은 조합은 우선순위 하락)
- **절대적 외모 점수 없음** — 오직 관계별 방향 예측만 존재
- Dealbreaker 양방향 필터
- **하루 제한 추천** (Free 2명 / Plus 4명), 무한 스와이프 없음
- **알고리즘 공정성**: confident(높은 확신) / other_strength(내면 궁합 강함) /
  explore(탐색) 3버킷 혼합으로 노출 기회 보장
- 사용자에게 원시 점수·퍼센트를 노출하지 않음 (문구 단계만 표시)

### 커뮤니케이션
- 상호 호감 시에만 매칭 (한쪽만 선택하면 상대에게 비공개)
- 매칭 후 무제한 채팅 + **AI Icebreaker** (두 사람의 공통점 기반 첫 대화 주제)
- 대화가 일정 수준 진행되면 **"실제로 만나보고 싶나요?"** (YES / NOT YET) —
  둘 다 YES일 때만 서로에게 알림
- **만남 후 피드백** — "실제 모습이 취향이었나요?" 답변으로 외모 취향 벡터를 실측 보정

### 학습 (개인 Dating Model의 시작)
- 선택 행동(호감/지나침), 첫 메시지, 답장, 만남 의사, 피드백을 `behavior_events`에 기록
- **AI Dating Coach**: 매칭을 조작하지 않고, 내 행동 데이터를 나에게 돌려주는 분석

### 안전 (전부 무료)
- 신고 / 차단, 첫 만남 안전 가이드 문구

### 수익화
- Free로도 실제 연애까지 전 과정 가능
- Plus(데모 전환)는 **추천 기회·편의만** 확대 — 매칭 알고리즘 품질은 Free와 동일
- 부스트·상단 노출·Super Like·외모 점수 판매 등은 원칙적으로 구현하지 않음

## 기술 구성

| 영역 | 선택 |
|---|---|
| 프레임워크 | Next.js 15 (App Router) + React 19 + TypeScript |
| DB | SQLite (better-sqlite3) — `data/app.db` 자동 생성·시드 |
| 인증 | 쿠키 세션 (모의 SMS 인증) |
| 매칭 엔진 | `lib/matching.ts` — 벡터 유사도 + 개인 가중치 + 조화 평균 |

## MVP에서 모의(mock)로 처리한 것

실서비스 전 교체가 필요한 지점:

1. **휴대전화 본인 인증** — PASS/NICE 등 본인확인 기관 연동
2. **얼굴 라이브니스 + 임베딩** — 온디바이스 라이브니스 SDK + 얼굴 임베딩 모델
   (현재는 사용자별 결정적 모의 벡터)
3. **가상 얼굴 A/B 테스트** — 생성형 얼굴 이미지 (현재는 특징 벡터 기반 SVG 일러스트)
4. **결제** — 앱 내 결제/PG 연동 (현재는 전환 시뮬레이션)
5. **데모 사용자** — `is_demo=1` 시드 사용자는 자동 호감/자동 응답으로
   매칭 플로우를 체험할 수 있게 함. 실배포 시 제거.
